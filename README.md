### Project Name:
Calendar Planner / Calendar Note-Taker 🗓️ 

### Application Description:

**Calendar Planner** is a web tool that integrates note-taking capabilities with an online calendar to keep track of daily tasks or memorable moments. It aims to help users stay organized by combining scheduling and journaling in one seamless experience when most people sometimes forget to keep track of their daily tasks and do not have a physical planner on hand. Many existing calendar tools lack flexible note-taking features, forcing users to juggle between multiple apps for planning their day and recording thoughts or tasks. The Calendar Planner will offer a clean interface that allows users to plan their schedule with an interactive calendar, attach notes to specific days, and create notes for thoughts, ideas, or tasks.



### Features + Tools/Technologies:

- Visual calendar (month/week/day along with grid cards for each day of the month) 
  - React.js + FullCalendar
  - CSS for design
  - Html

- Note generation (yellow tab in each grid of the day)
  - React.js
  - CSS
  - Html
